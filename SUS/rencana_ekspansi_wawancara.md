### B. Pertanyaan Inti SUS (Adaptasi dari Brooke 1996)

> **Instruksi:** "Setelah mencoba menggunakan sistem Sellica, mohon jawab pertanyaan berikut dengan skala 1-5."

#### Soal Positif (Skor = Jawaban - 1)

| No | Pertanyaan | Skala |
|----|------------|-------|
| **1** | "Apakah Bapak/Ibu merasa **ingin menggunakan** sistem Sellica secara rutin dalam pekerjaan sehari-hari?" | 1 = Sangat Tidak Ingin → 5 = Sangat Ingin |
| **3** | "Secara keseluruhan, seberapa **mudah** sistem Sellica digunakan oleh Bapak/Ibu?" | 1 = Sangat Sulit → 5 = Sangat Mudah |
| **5** | "Menurut Bapak/Ibu, apakah **fitur-fitur** dalam sistem Sellica terhubung dengan baik dan saling mendukung?" | 1 = Sangat Tidak Terpadu → 5 = Sangat Terpadu |
| **7** | "Menurut Bapak/Ibu, seberapa **cepat** seseorang yang baru pertama kali menggunakan sistem ini bisa langsung mengoperasikannya?" | 1 = Sangat Lama → 5 = Sangat Cepat |
| **9** | "Seberapa **yakin** Bapak/Ibu bisa menggunakan sistem ini tanpa bantuan siapapun?" | 1 = Sangat Tidak Yakin → 5 = Sangat Yakin |

#### Soal Negatif (Skor = 5 - Jawaban)

| No | Pertanyaan | Skala |
|----|------------|-------|
| **2** | "Menurut Bapak/Ibu, apakah sistem Sellica terasa **rumit** atau membingungkan saat digunakan?" | 1 = Sangat Rumit → 5 = Sangat Sederhana |
| **4** | "Apakah Bapak/Ibu merasa membutuhkan **bantuan orang teknis** (IT) untuk bisa menggunakan sistem ini?" | 1 = Sangat Butuh → 5 = Tidak Butuh Sama Sekali |
| **6** | "Apakah tampilan dan cara penggunaan sistem Sellica **konsisten** dari satu halaman ke halaman lain?" | 1 = Sangat Tidak Konsisten → 5 = Sangat Konsisten |
| **8** | "Apakah Bapak/Ibu merasa **kesulitan menemukan** fitur atau menu yang dibutuhkan dalam sistem?" | 1 = Sangat Kesulitan → 5 = Sangat Mudah |
| **10** | "Apakah Bapak/Ibu perlu **banyak belajar** terlebih dahulu sebelum bisa menggunakan sistem ini?" | 1 = Sangat Banyak → 5 = Tidak Perlu Belajar |

## 4. Metodologi & Validitas

### Justifikasi Sample Size

| Aspek | Penjelasan |
|-------|------------|
| **Minimum untuk SUS** | 5-8 responden (Brooke, 1996) |
| **Recommended untuk Riset** | 20+ responden (Sauro, 2011) |
| **Untuk Tesis/Skripsi** | 20-30 responden (standar dosen Indonesia) |
| **Target Kita** | **20 responden** — memenuhi standar akademik |

### Mixed Methods Design

```
┌─────────────────────────────────────────────────────────────┐
│                    QUANTITATIVE (SUS)                        │
│  • 20 responden × 10 soal Likert                            │
│  • Skor SUS per responden (0-100)                           │
│  • Rata-rata + standar deviasi                              │
│  • Kategorisasi (Worst → Best Imaginable)                   │
└─────────────────────────────────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────┐
│                    QUALITATIF (Wawancara)                    │
│  • Pertanyaan follow-up per soal                            │
│  • 13 pertanyaan tambahan (fitur spesifik)                  │
│  • Triangulasi data                                         │
└─────────────────────────────────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────┐
│                    ANALISIS                                  │
│  • Perbandingan antar bidang (IT vs non-IT)                 │
│  • Korelasi lama kerja vs skor SUS                          │
│  • Temuan kualitatif → rekomendasi perbaikan                │
└─────────────────────────────────────────────────────────────┘
```
